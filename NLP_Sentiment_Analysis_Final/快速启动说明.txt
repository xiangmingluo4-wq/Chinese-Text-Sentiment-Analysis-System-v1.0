一、系统简介
================================================================================
本系统是一个基于规则优先 + XGBoost + 特征工程的中文三分类情感分析Web应用，支持：
  ✅ 批量分析 - 上传CSV文件，批量分析情感倾向
  ✅ 单句分析 - 输入单条文本，实时分析情感
  ✅ 智能客服 - 情感联动问答，负面情绪自动安抚
  ✅ 反馈闭环 - 用户纠错后自动重训，模型持续进化
技术特点：
  🚀 开箱即用，一键启动
  📊 可视化图表展示
  🔧 完整的工程化架构
  💡 多个创新加分功能
  ⚡ 轻量级XGBoost模型（<50MB），推理速度快
  🎯 规则硬拦截 + 模型预测双保险，准确率更高

三、快速启动（推荐）
================================================================================
【Windows 用户】
  1. 双击运行 start.bat
  2. 等待自动安装依赖（首次运行较慢）
  3. 浏览器会自动打开 http://localhost:5000
  4. 开始使用！
【Mac / Linux 用户】
  1. 打开终端，进入项目目录
  2. 运行命令：chmod +x start.sh && ./start.sh
  3. 等待自动安装依赖
  4. 浏览器访问 http://localhost:5000
================================================================================
四、手动启动（进阶）
================================================================================
步骤1：创建虚拟环境（可选但推荐）
  python -m venv venv
  Windows: venv\Scripts\activate
  Mac/Linux: source venv/bin/activate
步骤2：安装依赖
  pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
步骤3：初始化目录
  python config.py
步骤4：启动服务
  python app.py
步骤5：访问系统
  打开浏览器，访问 http://localhost:5000

五、功能使用说明
================================================================================
【Tab1：批量分析】
  1. 点击上传区域或拖拽CSV文件
  2. 等待分析完成（10000条约需几秒）
  3. 查看统计卡片和可视化图表
  4. 点击"导出结果"下载分析结果
  CSV文件格式要求：
    - 必须包含 text 列（评论文本）
    - 可选包含其他列，会原样保留
【Tab2：单句分析】
  1. 在输入框中输入中文文本
  2. 点击"开始分析"按钮
  3. 查看情感结果、置信度和关键词
  4. 可继续输入新的文本测试
  5. 如发现分析错误，可点击"纠错"提交反馈
【Tab3：智能客服】
  1. 在输入框中输入问题
  2. 点击发送或按回车
  3. 查看机器人回答
  4. 负面情绪会自动触发安抚

七、常见问题
================================================================================
Q1：启动时提示"Python不是内部或外部命令"
A：请先安装Python，并确保已添加到系统环境变量中。
   下载地址：https://www.python.org/downloads/
Q2：依赖安装很慢怎么办？
A：脚本已默认使用清华镜像源，如果还是慢，可以手动运行：
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
Q3：端口5000被占用怎么办？
A：可以修改 config.py 中的 FLASK_PORT 配置，改成其他端口。
Q4：模型文件不存在怎么办？
A：运行训练脚本生成模型：
   python train/train_model.py
Q5：如何重新生成数据？
A：运行数据生成脚本：
   python train/data_generator.py
Q6：如何运行自动化质检？
A：运行质检脚本：
   python code/07_auto_quality_check.py
Q7：XGBoost安装失败怎么办？
A：系统会自动降级为SVM模型，功能不受影响，只是准确率略低。
   如需安装XGBoost：pip install xgboost
Q8：如何使用反馈功能？
A：在单句分析页面，如发现分析结果错误，点击"纠错"按钮，
   选择正确的情感标签提交。系统会自动收集反馈，每收集10条
   反馈会自动触发模型重训，实现持续进化。
