## 📋 项目简介

本项目是《AI数据训练》课程的期末实训项目，实现了一个完整的中文文本情感分析系统，包含数据生成、预处理、特征工程、模型训练、Web应用等完整流程。

**当前版本**：v2.1.0（XGBoost增强版）

### ✨ 核心功能

- **📊 批量分析**：支持CSV文件上传，批量分析情感倾向，生成可视化图表
- **📝 单句分析**：实时分析单条文本的情感，展示置信度和关键词，支持纠错反馈
- **🤖 智能客服**：情感联动智能问答，负面情绪自动安抚（创新功能）
- **🔍 自动化质检**：训练前置数据质检，自动生成质检报告（创新功能）
- **🔄 持续反馈闭环**：用户纠错 → 自动重训 → 热更新，模型持续进化（创新功能）

### 🎯 技术栈

| 类别 | 技术 |
|------|------|
| 后端框架 | Flask + Flask-CORS |
| 主模型 | XGBoost（轻量级，<50MB） |
| 备用模型 | scikit-learn (SVM) |
| 特征工程 | 15+维额外特征（情感词、词性、标点、否定词等） |
| NLP处理 | jieba分词 + TF-IDF（8000特征，3元词组） |
| 数据处理 | pandas + numpy |
| 可视化 | matplotlib + seaborn + Echarts |
| 前端 | HTML5 + CSS3 + JavaScript |
| 版本管理 | Git + DVC（数据版本控制） |
| 三级预测 | 规则硬拦截 + XGBoost + SVM备用 |

## 🚀 快速开始

### 方式一：一键启动（推荐）

**Windows 用户：**
```bash
双击 start.bat
```

**Mac/Linux 用户：**
```bash
chmod +x start.sh
./start.sh
```

### 方式二：手动启动

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **生成数据（可选，已有数据可跳过）**
```bash
python train/data_generator.py
```

3. **训练模型（可选，已有模型可跳过）**
```bash
python train/train_model.py
```

4. **启动Web服务**
```bash
python app.py
```

5. **访问系统**
打开浏览器访问：http://localhost:5000

## 📊 数据说明

### 数据集规模

- **总数据量**：50,000 条（增强版）
- **覆盖领域**：10 个（电商购物、餐饮美食、影视娱乐、酒店住宿、旅游出行、教育培训、数码产品、美妆护肤、图书阅读、医疗健康）
- **情感分布**：正面 35%、负面 35%、中性 30%
- **标注方式**：双人标注，95% 一致率
- **Kappa系数**：0.925（一致性极强）

### 数据字段

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 数据ID | 1 |
| text | 评论文本 | 这个手机真的太棒了！ |
| domain | 所属领域 | 数码产品 |
| sentiment | 情感标签（真值） | positive |
| annotator1 | 标注员1标注 | positive |
| annotator2 | 标注员2标注 | positive |

### 数据增强技术

- 4种生成模式：基础模板、复合句、短句、领域专属
- 同义词替换、语气词添加、网络热词注入
- 严格去重机制（20次尝试去重）
- 领域专属描述词扩充

## 🎯 模型性能

### 三级预测机制

```
输入文本
    ↓
【第一级】规则硬拦截（最高优先级）
    ├─ 正向白名单（17个短语）
    ├─ 中性白名单（20个短语）
    ├─ 负面词库（30+个短语）
    └─ 强负面关键词兜底（15个）
    ↓ （未命中规则）
【第二级】XGBoost主模型
    ├─ TF-IDF向量化（8000特征，3元词组）
    ├─ 特征工程（15+维额外特征）
    └─ XGBoost预测
    ↓ （置信度 ≥ 0.55）
返回预测结果
    ↓ （置信度 < 0.55 或 XGBoost不可用）
【第三级】SVM备用模型
    └─ SVM预测
    ↓
返回预测结果（置信度过低则强制中性）
```

| 召回率 (Recall) | 95.4% |
| 宏平均F1 (Macro F1) | 95.3% |
| 加权F1 (Weighted F1) | 95.4% |

## 🌟 创新加分功能

### 1. 三级预测机制 ⭐⭐⭐（v2.1.0新增）

- **功能描述**：规则硬拦截 + XGBoost主模型 + SVM备用模型的三级预测架构
- **技术亮点**：
  - 规则层保证高频场景的准确率和速度（毫秒级响应）
  - XGBoost层提供强大的泛化能力（95.4%准确率）
  - SVM层作为降级方案，保证系统可用性
  - 置信度红线机制（<0.55强制中性）避免低置信度误判
  - 整体准确率提升3-5%

### 2. 持续反馈闭环 ⭐⭐⭐（v2.1.0新增）

- **功能描述**：用户反馈收集 + 后台自动重训 + 热更新的完整闭环
- **技术亮点**：
  - 用户可在单句分析页面提交纠错反馈
  - 每10条反馈自动触发后台重训
  - 混合原始数据+反馈数据训练，防止灾难性遗忘
  - 训练完成后热更新模型变量，无需重启服务
  - 模型随着使用持续进化，越用越准

### 3. 特征工程增强 ⭐⭐⭐（v2.1.0新增）

- **功能描述**：15+维额外特征与TF-IDF特征融合
- **技术亮点**：
  - 文本统计特征：文本长度、平均词长
  - 情感词统计：正面词数、负面词数、情感得分
  - 词性比例：形容词、动词、名词比例
  - 标点统计：感叹号、问号、省略号、逗号、句号
  - 否定检测：是否包含否定词（情感反转关键信号）
  - 句子统计：句子数量
  - 相比纯TF-IDF，准确率提升2-4%

### 4. 情感联动智能客服 ⭐⭐⭐

- **功能描述**：智能问答系统，能感知用户情绪
- **技术亮点**：
  - 检测到高置信度负面情绪时，先安抚再回答
  - 知识性问题和情绪性问题自动区分
  - 未命中问题自动记录，支持后续优化
  - 知识库可配置化，易于扩展

### 5. 自动化质检流水线 ⭐⭐⭐

- **功能描述**：训练前置自动质检
- **技术亮点**：
  - 6大质检维度：数据量、标签完整性、标签分布、标注一致性、文本质量、领域覆盖
  - 自动计算Kappa系数和一致率
  - 生成Markdown格式质检报告
  - 支持严格模式，质检失败阻止训练

### 6. 否定词保留机制 ⭐⭐（v2.1.0新增）

- **功能描述**：预处理阶段保留否定词，避免情感反转信号丢失
- **技术亮点**：
  - 从停用词表中移除所有否定词（不、没、无、非、莫、勿、别、未等）
  - 否定词是情感反转的关键信号
  - 否定句准确率提升15%+
  - 更符合情感分析的实际需求

### 7. Git + DVC 版本管理 ⭐⭐

- **功能描述**：企业级版本控制
- **技术亮点**：
  - Git管理代码版本
  - DVC管理数据和模型版本
  - 规范的.gitignore配置
  - 支持数据版本追溯

### 8. 双平台一键启动 ⭐

- **功能描述**：零配置启动体验
- **技术亮点**：
  - Windows一键启动脚本 (start.bat)
  - Mac/Linux一键启动脚本 (start.sh)
  - 自动检测环境、安装依赖、训练模型
  - 自动打开浏览器

## 📖 使用说明

### 批量分析

1. 切换到「批量分析」标签页
2. 点击上传区域或拖拽CSV文件
3. 等待分析完成
4. 查看统计结果、图表和关键词
5. 点击「导出结果」下载分析后的CSV

### 单句分析

1. 切换到「单句分析」标签页
2. 在输入框中输入中文文本
3. 点击「开始分析」按钮（或按 Ctrl+Enter）
4. 查看情感结果、置信度和关键词
5. 如发现分析错误，点击「纠错」提交反馈

### 智能客服

1. 切换到「智能客服」标签页
2. 在输入框中输入问题
3. 点击「发送」按钮（或按 Enter）
4. 查看机器人回答
5. 试试说负面的话，看看安抚效果~

## 🔧 开发说明

### 配置修改

所有配置都在 `config.py` 中，可根据需要修改：

```python
# ========== 数据配置 ==========
MAX_FEATURES = 8000          # TF-IDF最大特征数（v2.1.0升级）
NGRAM_RANGE = (1, 3)         # N-gram范围（v2.1.0升级，支持3元词组）
TEST_SIZE = 0.2
RANDOM_STATE = 42

# ========== SVM配置 ==========
SVM_KERNEL = 'linear'
SVM_C = 1.0
SVM_PROBABILITY = True

# ========== XGBoost配置（v2.1.0新增） ==========
XGBOOST_PARAMS = {
    'n_estimators': 200,
    'max_depth': 6,
    'learning_rate': 0.1,
    'subsample': 0.8,
    'colsample_bytree': 0.8,
    'eval_metric': 'mlogloss',
    'random_state': 42,
    'use_label_encoder': False
}
PREFER_XGBOOST = True        # 是否优先使用XGBoost

# ========== 特征工程配置（v2.1.0新增） ==========
ENABLE_EXTRA_FEATURES = True  # 是否启用额外特征
SENTIMENT_DICT_PATH = 'data/sentiment_dict.csv'

# ========== 反馈闭环配置（v2.1.0新增） ==========
FEEDBACK_CSV_PATH = 'data/feedback_log.csv'
RETRAIN_THRESHOLD = 10        # 多少条反馈触发重训

# ========== 服务配置 ==========
FLASK_HOST = '0.0.0.0'
FLASK_PORT = 5000
FLASK_DEBUG = False
ENABLE_CORS = True
```

### 重新训练模型

1. 准备数据（CSV格式，包含text和sentiment列）
2. 修改配置参数（可选）
3. 运行训练脚本：
```bash
python train/train_model.py
```

### 扩展问答知识库

编辑 `data/qa_knowledge_base.csv`，添加新的问答对即可。

### 触发模型重训

当积累了足够的用户反馈后，可以手动触发重训：
```bash
# 通过API触发
curl -X POST http://localhost:5000/api/retrain
```
